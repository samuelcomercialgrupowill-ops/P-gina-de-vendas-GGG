Skill de Edição

A IA assiste a live, acha os melhores momentos, corta em pé, legenda palavra por palavra e dá zoom nas reações. Guia de instalação e uso.

Uso pessoal do aluno Corte Pronto. Proibida a revenda.

O que a Skill faz

A Skill de Edição é um "manual de trabalho" que você instala no Claude, junto com um programa de edição. Você manda a live, e o Claude:

  1. Transcreve a live inteira, com o tempo de cada palavra;
  2. Lê tudo e escolhe os trechos com mais chance de prender;
  3. Te mostra o plano (início, fim, motivo e gancho de cada corte) para você aprovar;
  4. Edita: corte em pé 1080×1920, fundo desfocado, legenda palavra por palavra com destaque colorido, zoom nas reações e título de gancho no topo;
  5. Entrega os arquivos prontos e sugere a legenda do post.

Os arquivos da skill estão no .zip que acompanha este bônus na área de membros: as pastas corte-pronto e editor-com-ia.

Instalação no Windows

1. Instale o Python

Baixe em python.org/downloads. Na primeira tela do instalador, marque "Add python.exe to PATH" e clique em Install Now.

2. Instale o ffmpeg

Abra o PowerShell (procure no menu Iniciar) e cole:

winget install --id Gyan.FFmpeg -e

Feche e abra o PowerShell de novo e confira com ffmpeg -version.

3. Instale o transcritor

pip install faster-whisper

4. Coloque a skill no Claude

  1. Extraia o .zip.
  2. Abra a pasta C:\Users\SEU_USUARIO\.claude\skills (se a pasta skills não existir, crie).
  3. Copie para dentro dela as pastas corte-pronto e editor-com-ia.

Instalação no Mac

Abra o Terminal e cole, uma linha por vez:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" brew install python ffmpeg pip3 install faster-whisper mkdir -p ~/.claude/skills

Depois copie as pastas corte-pronto e editor-com-ia para ~/.claude/skills (no Finder: menu Ir → Ir para a Pasta → ~/.claude/skills).

Como usar

1. Tenha o arquivo da live

Baixe o vídeo da live (VOD) de um streamer que autoriza cortes e coloque numa pasta, por exemplo Documentos\Cortes. Respeite as regras da plataforma e do streamer.

2. Abra o Claude Code nessa pasta

No app do Claude, abra o Claude Code e escolha a pasta onde está a live.

3. Peça os cortes

Use a skill corte-pronto e faça 3 cortes da live.mp4 no estilo viral.

O Claude vai transcrever (pode levar alguns minutos em live longa), te mostrar o plano dos cortes e, depois que você aprovar, gerar os vídeos na mesma pasta.

Outros pedidos que funcionam

  • "Faz 5 cortes curtos, de 20 a 30 segundos, só de reações."
  • "Quero um top 3 da live com título em cada um."
  • "Usa o estilo gamer e coloca zoom quando ele grita."
  • "Refaz o corte 2 começando 3 segundos antes."

Estilos prontos

EstiloVisual
viralLegenda branca grande, palavra da vez em amarelo, maiúsculas, zoom médio, fundo desfocado.
gamerFonte Impact, destaque ciano, 2 palavras por vez, zoom forte, tela cheia.
limpoLegenda branca discreta, frase inteira, sem zoom. Bom para podcast.

Quer um estilo só seu? Use o Bônus 4, Editor com IA Automático.

Problemas comuns

Aparece…Faça…
"ffmpeg não encontrado"Refaça o passo 2 da instalação e abra um terminal novo.
"Falta o transcritor"Rode pip install faster-whisper.
Transcrição muito lentaNormal na primeira vez (ele baixa o modelo). Em PC mais fraco, peça para usar --modelo base.
Nome escrito errado na legendaPeça: "corrige o nome X na transcrição e refaz o corte".
